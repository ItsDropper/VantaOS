# Getting help

VantaOS is an experimental hobby operating system maintained by one person.
There is no guaranteed response time.

| I want to… | Go to |
| --- | --- |
| Build or boot VantaOS | [Getting started](docs/GETTING_STARTED.md), then open a [bug report](https://github.com/ItsDropper/VantaOS/issues/new?template=bug_report.yml) |
| Understand a concept | [Documentation index](docs/README.md), [glossary](docs/GLOSSARY.md) |
| Propose a feature | [Feature request](https://github.com/ItsDropper/VantaOS/issues/new?template=feature_request.yml) |
| Report a security problem | [Security policy](SECURITY.md); do **not** open a public issue |
| Contribute | [Contributing guide](CONTRIBUTING.md) |

When reporting a problem include: the commit hash, host OS, the exact commands
run, the serial log, and whether it was QEMU (with the `run.sh` settings) or
real hardware. Hardware reports without logs cannot be acted on.
